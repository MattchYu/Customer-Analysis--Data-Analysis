# Customer Shopping Behavior Analysis (In Progress)

##  Project Overview

This project demonstrates a complete, industry-style end-to-end data analytics workflow designed to mirror real-world analyst responsibilities. It covers every major phase of the analytics lifecycle—from data cleaning and modeling to insight generation, visualization, and reporting.

The goal of this project is to analyze customer shopping behavior data to uncover purchasing trends, customer segments, and business insights that can help improve marketing, sales strategy, and customer retention.

---

##  Objectives

* Clean and preprocess raw customer shopping data
* Perform exploratory data analysis (EDA)
* Identify key purchasing patterns and trends
* Build SQL queries to extract business insights
* Create dashboards and visualizations
* Present findings in a professional report format

---

##  Dataset

**File:** `customer_shopping_behavior.csv` From Amlan Mohanty 

The dataset contains customer transaction information such as:

* Customer ID
* Gender
* Purchase Amount
* Discount Applied
* Product Information
* Other behavioral indicators

This dataset is used to simulate real-world retail analytics scenarios.
